# Бит Джигит — сайт артиста

Статический сайт-визитка: треклист, мифология нартов, видео, форма связи.
Тёмная горная тема, акценты золото/янтарь, SVG-горы и 12 звёзд (символика Адыгеи).

## Структура

- `index.html` — вся разметка, одна страница
- `css/styles.css` — стили
- `js/main.js` — мобильное меню, отправка формы связи
- `assets/` — favicon и графика
- `.github/workflows/deploy.yml` — автодеплой на GitHub Pages при пуше в `main`

## Что нужно доделать перед публикацией

1. **Форма связи** — вставить свой публичный ключ Web3Forms в `index.html`
   (`YOUR_WEB3FORMS_ACCESS_KEY`, в двух местах: hidden-поле формы). Ключ бесплатный,
   получить на https://web3forms.com — это публичный ключ, его можно смело хранить в коде.
2. **Ссылки на платформы и соцсети** — сейчас все `href="#"` с `data-platform`/`data-link`.
   Нужно проставить реальные ссылки: Яндекс Музыка, VK Музыка, МТС Music, YouTube (Серна-мэн),
   VK-сообщество.
3. **Включить GitHub Pages**: Settings → Pages → Source: "GitHub Actions". После этого
   workflow задеплоит сайт автоматически при следующем пуше в `main`.

## Локальный просмотр

Просто открыть `index.html` в браузере, либо через любой статический сервер, например:

```
npx serve .
```
